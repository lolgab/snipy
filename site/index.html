Python,natively. Python,natively.

snipy embeds CPython in your Scala Native binary and calls it straight through the C API. No FFI layer, no subprocess, no JVM.

Write Scala. Run Python.

The Python it runs

import json
json.dumps({"a": [1, 2]}, indent=2)

What snipy does

  1. Converts Map("a" -> List(1, 2)) to a dict
  2. Passes indent=2 as a keyword argument
  3. Calls json.dumps with one vectorcall

What it can do

  • Modules, attributes, methods and keyword arguments, written the way Python writes them.

    val np = module("numpy")
np.linspace(0, 1, num = 5)

  • Arguments are converted by a macro. A value with no conversion is a compile error, not a crash.

    math.sqrt(new Object)
// error: no AsPython[Object] instance

  • Functions of up to three arguments become Python callables, released when Python drops them.

    builtins.sorted(words, key = (s: String) => s.length)

  • A raised exception becomes PythonException, with Python's type, message and traceback.

    catch case e: PythonException =>
  e.pythonType // json.decoder.JSONDecodeError

  • The Scala Native GC releases references through java.lang.ref.Cleaner. Py.local releases them on the spot.

    Py.local {
  np.random.rand(1000, 1000).sum().as[Double]
}

  • The GIL is taken around every operation, and blocking calls never stall the garbage collector.

    Python.withGil {
  (1 to 1000).map(Py(_)).reduce(_ + _)
}

  • An opaque type over Py gives a Python class a Scala type, with no wrapper allocated.

    opaque type Fraction = Py
extension (f: Fraction) def +(g: Fraction): Fraction = ...

  • Numbers, BigInt, strings, bytes, options, collections and tuples of any size, plus your own types.

    json.loads(text).as[Map[String, List[(Int, String)]]]

Nothing matches. The guide has everything.

No refcounting by hand

Each Python object stays alive exactly as long as a Scala value points at it.

snipy registers every object with Scala Native's java.lang.ref.Cleaner. When the garbage collector drops the Scala side, the Python reference is released, under the GIL, on the next call. For loops that make big arrays, Py.local and dispose() release them on the spot.

How memory is managed

Tested on every push

Against Python 3.12, 3.13, 3.14 and 3.15, Scala 3.3 LTS and 3.10, Scala Native 0.5.12, on Linux and macOS. The test suite also runs under the immix, commix and Boehm collectors.

Add it to your build

One dependency and one linker setting that finds libpython. The interpreter starts the first time you touch a Python object.

libraryDependencies += "com.github.lolgab" %%% "snipy" % "0.1.0"

nativeConfig ~= { config =>
  val python = sys.env.getOrElse("SNIPY_PYTHON", "python3")
  def sysconfig(name: String) =
    Seq(python, "-c", s"import sysconfig; print(sysconfig.get_config_var('$name'))").!!.trim
  val libDir = sysconfig("LIBDIR")
  config.withLinkingOptions(
    _ ++ Seq(s"-L$libDir", s"-Wl,-rpath,$libDir", s"-lpython${sysconfig("LDVERSION")}")
  )
}
